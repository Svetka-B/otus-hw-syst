## Описание проекта
Домашнее задание №10 урока 19 по курсу Инфраструктура высоконагруженных систем от OTUS. Развертывание виртуальных машин на Proxmox с помощью Terraform 
Цель работы: 
Научиться писать Terraform-скрипты для развёртывания виртуальных машин в Proxmox

Описание выполнения домашнего задания в соответствии:
1) Развернула Proxmox как ВМ в VMwimare
2) После первоначальной настройки подкинула ISO образ дистрибутива Ubuntu
3) Создала тестовую ВМ №110
4) Произвела первоначальную настройку и сделала из этой ВМ шаблон
5) Создала ВМ админа №666 на которую установила Terraform
6) Написала манифест для развёртывания ВМ для домашнего задания №4 https://github.com/Svetka-B/otus-hw-syst/tree/HW4
7) Запустила terraform apply и проверила, что ВМ созданы
